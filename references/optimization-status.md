## 常见错误

- **没发现目标**：查看扫描 roots 和 errors，再指定已核验目录；不把 partial 当不存在。
- **AppID/头错误**：确认目标身份与格式；保留原快照，不猜解码结果。
- **输出被修改/锁冲突**：审阅范围后使用新目录或等待其他进程完成；不覆盖用户数据。
- **手写旧清单不兼容**：保留旧记录，从原缓存重新提取当前工具清单后核对哈希。
- **分包仍缺**：记录正常入口、下载/权益原因；不强制隐藏路由。
- **静态分析 unknown**：定位原模块补人工调用链，不能执行整包解决。
- **公开报告被降级**：检查附件相对路径、真实哈希、结果声明；不要直接改 status。
- **打包拒绝文件**：检查秘密、个人路径、意外文件/二进制、symlink 与依赖目录；不要削弱检查。

## v1.1.0：微信功能拆解补强

| 补强 | 实际实现 | 边界 |
| --- | --- | --- |
| 专用范围 | Skill 入口、路由与提示词限微信 | 浏览器仅为复刻输出；不安装 REA、不扩展网站/APP |
| 按功能阅读 | feature_tool 字面量/模块候选、源码位置与摘要 | 不自动得到全量依赖或真实调用图 |
| 可定位证据 | AppID/版本/清单/分析哈希绑定、逐文件读回 | 哈希验证材料，不能证明作者身份和执行语义 |
| 行为线索 | 存储/导出/导航/setData 与最近函数名 | 别名、动态成员、事件绑定与异步执行另追踪 |
| 未知与省略 | unresolved、无匹配、旧分析、返回/省略计数 | 不将静态范围完整升级为产品完整 |
| 观察分层 | 原程序和复刻分别记录动作、结果、时间、附件 | 人工观察附件字节通过仍需语义审阅 |
| 学习交付 | features 文档、feature-map 和观察模板 | 源材料、推断和独立实现分别标明 |
