# 微信输入与本地复刻能力矩阵

本技能专门研究微信小程序缓存包。浏览器是复刻输出环境；用户明确要求时可适配自己的微信小程序。通用网站、原生 APP、其他平台小程序逆向另行路由，不在本技能中扩展。

这是适配与验收规划，不代表已完成接入。实施平台能力时查微信官方文档并记录 SDK 版本。发布仅按当次明确授权执行。

| 能力 | 本地浏览器复刻 | 自己的微信小程序 |
| --- | --- | --- |
| UI/样式/Canvas | DOM/CSS/Canvas 适配，实际浏览器验收 | 组件与 Canvas 能力，开发工具/真机验收 |
| 登录 | 本地身份模拟或自己的后端会话 | 自己的 AppID、登录 code 与服务端换会话 |
| 本地存储 | localStorage/IndexedDB，刷新读回 | 微信 storage，真机读回 |
| 文件/图片导出 | 浏览器下载或本地服务写出 | 微信文件/相册接口与权限 |
| 云端数据 | 授权 API + 本地服务代理 | 请求域名与自己后端权限 |
| 订阅/通知 | 本地模拟或自主实现 | 模板、用户授权、登记和发送后端 |
| 广告 | 标记模拟/未接入 | 自己可用的广告位、完成处理 |
| 会员/支付 | 本地演示或自己的支付服务 | 商品、签名、查单/发货/权益，各自实测 |
| 分享 | 浏览器链接/本地演示 | 微信原生分享与跳转 |
| 交付 | localhost 可见、源码与实际验收 | 用户要求的微信工程；审核、发布另授权 |

优先学习已核验纯业务函数与数据结构，原生桥接放 adapter；原件提取、推断和独立实现分别注明。配置 Key、打开开发工具、构建通过和正式上线是不同状态。

仅做本地版时不要求用户提前提供微信 AppSecret 或支付签名。需要原生能力时，补全表列类别、提供者与私密配置位置，密钥留服务端，不进入源码、报告或公开仓库。
