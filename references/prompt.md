# 启动提示词与准备

## 最少准备

提供目标名称/AppID、已在电脑打开或可提供的包、交付目标和必要截图。正常打开各 tab、核心操作和列表分页可补按需缓存；保留原缓存。不能访问的会员态、下载失败、入口不存在分别说明，不借研究绕过权益。

## 完整解析并复刻

```text
使用 $miniapp-cache-rebuild 解析我已打开的【目标】。
先交叉核对身份与当前界面，盘点指定范围内全部版本、主包、分包及扫描失败。
正常访问补按需缓存，保留访问记录、补前/补后差异和未取得原因。
保留原缓存，在【新目录】快照、解码，检查索引、正文覆盖、全部文件读回哈希。
建立资产/页面状态/UI/核心流程/接口认证/提示词证据地图。
区分预览与原图、客户端与后台、静态/快照/模拟/实时数据；列缺失材料与接入验收。
在独立工程复刻本地浏览器版，实际测试保存、刷新恢复和导出文件。
同状态同视口对照截图，开 localhost 服务器，交付源码、地址、报告及具体差异。
本地学习，不发布、不付款、不向原服务上传资料。
```

## 只做研究

```text
使用 $miniapp-cache-rebuild 只研究【目标】，不修改应用、不连接需认证的业务接口。
交付缓存与版本清单、可核验的前端证据、真实存在的提示词、缺失分包和后端补全表。
```

## 续作

```text
继续【目标】的已有研究，证据目录为【路径】，已选版本为【版本】。
先核对已有范围和哈希，增量处理新增缓存；不覆盖已被修改的输出，不混入其他账号版本。
优先补【页面/状态/接口】，更新变化和验收，不重复无变化的测试。
```

本技能输入只限微信小程序。浏览器复刻之后如需移植为自己的微信小程序，另记录自己的平台账号、AppID、原生能力与实际验收；发布仅按明确授权执行。

## 按功能学习并模仿

```text
使用 $miniapp-cache-rebuild 研究我在电脑微信打开的【目标】的【保存/导出/识别/刷新功能】。
先核对 AppID、版本、主包与相关分包，保留原缓存并验证解码与哈希。
完成静态分析后按实际页面/方法名生成私有功能档案，列匹配与省略范围、证据位置和未知项。
解释入口→事件/方法→输入/状态→处理/接口→存储/输出→错误/权限，区分静态推断与原程序观察。
在【新目录】独立实现这个功能，标明复用原件与新写部分，实际验证保存、刷新恢复和导出。
缺失后台、原始 WXML、高清资产或提示词时如实列材料，不猜成已恢复。
仅本地学习，不发布。
```
