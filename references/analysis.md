# 静态分析与前后端证据

## 使用

```sh
node scripts/analyze.cjs --out "/separate/evidence" --version 1
```

分析器处理原生微信 `define(...)` 编译模块与 WXSS，支持白名单常量和有限数组求值。不会执行未知包代码、加载动态网络模块或运行其中的 `require`。静态结果是定位材料，核心业务仍需人工追踪。

## 模块和版本

记录模块名、正文 SHA256、包与源文件、字符/行位置、分析器版本。去重以“模块名 + 内容哈希”为依据；同名不同内容保持全部变体并标冲突。编译容器/内嵌块重复次数、唯一模块数、业务模块数分开统计。

同 AppID 不同版本或账号不拼为一个模块集合。对当前版本声明路由建立“页面 → 分包 → 模块/视图/样式/资产 → 已访问状态”地图。一个资源存在不能证明整个页面可运行；缺入口或编译视图要单独列出。

## 样式、视图和绘图

WXSS 提取保留原 token、公共样式导入与未知 token；缺导入显式记录。浏览器转换单独输出，以视口宽度/750 换算 `rpx`；不要把变换后的 CSS 冒充原样式。

WXML 编译文件只提供视图结构线索，当前不能承诺还原开发者原始 WXML/组件源。Canvas 等纯函数先确认输入、平台依赖和输出，再考虑移植；样式提取通过不代表渲染等价。

## 动态数组与配置

数组可以通过 `push`、`concat`、静态变量引用追加。有限常量求值保存最终已解析值、操作出处和未解析表达式；越过白名单停止展开。模板数与图片条目/唯一图片数交叉检查，不将首段数组数当最终数，不将所有图片当独立模板。

## 接口与认证

从调用点追踪 `base + path`、方法、headers 的结构、参数、返回字段、错误、权限和请求触发。完整性等级：字面量调用 / 可静态展开 / 需要运行上下文 / 服务端未知。URL 字符串不等于实际调用；`WebSocket` 包装参数不等于建了连接，MCP 关键字也不等于调用。

凭证分开记录：公开 ID、用户 API Key、动态会话 token、服务端 secret、未知。只记录变量名/类别与配置位置，不复制真实值。原客户端登录会话和对外会员 API 是不同契约；不能借会话线索读取账号存储或进程凭证。

需真实联网验证时，使用已获授权的接口和凭证；记录 HTTP、权限、频率限制、响应时间与业务字段读回。自动生成的线索只能进入“待确认”，不标真实请求已通过。

## 提示词

| 分类 | 说明 |
| --- | --- |
| `candidate` | 关键词/字符串线索，尚未确认用途 |
| `actual_client_text` | 原客户端存在的完整文本，记录出处、用途、哈希 |
| `authorized_response` | 经授权返回/提供的实际文本，注明取得方式 |
| `server_unknown` | 客户端只能看到结果，提示词未取得 |
| `new_inference` | 为独立复刻新写，不是恢复原件 |

API 接入说明可以是真实提示词，但不是后台研判系统提示词。“读取系统提示”等 UI 文案也不能算系统提示原文。常量拼接只对白名单展开，未解析部分保留，不能用命中数量声称全部已取得。

## 存储、导出、导航与状态

分析器额外输出 `behaviors`：直接拼写的微信存储/文件导出/导航调用和 `setData`，附最近函数名、模块、源文件哈希和行位置。它们是静态语法候选，不验证接收对象、事件绑定、执行顺序或成功；别名与包装函数仍须阅读原文。使用 [features.md](features.md) 按功能生成有范围和省略数的私有档案，区分原程序观察与独立实现。

## 数据与刷新

每个关键字段记录 `static / snapshot / live / mock / unknown`、单位、取得时间、`generatedAt`、`updatedAt`、失效时间和范围。`live` 必须有实际请求/订阅证据；静态快照不能因为刷新 UI 而升级为实时。

区分本地动画/倒计时、网络轮询、后台采集/发布三个周期。概率预测、确认重置事件、官方服务异常、个人额度恢复也分开。费用估算和日志中的运行器标签不能当真实账单或后端 SDK 实现证据。
